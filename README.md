# LJT-Homepage

Personal academic homepage of Junteng Liu, first-year PhD candidate at the HKUST NLP Group, Hong Kong University of Science and Technology.

Built with the [Academic Pages template](https://github.com/academicpages/academicpages.github.io) and hosted on GitHub Pages.

## Setup

To enable GitHub Pages, go to **Settings → Pages → Source → GitHub Actions**. The site will be built and deployed automatically by the Jekyll workflow on each push to `master`.
